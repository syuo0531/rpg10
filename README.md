# Photo Vault — 写真保管庫

iPhoneのSafariなどで使える、端末内に写真を暗号化保存するウェブアプリです。

## 公開URL

GitHub Pagesでmainブランチのルートを公開した場合:
https://syuo0531.github.io/rpg10/

## 使い方

1. HTTPSの上記URLをSafariで開く。
2. 8文字以上のパスワードで保管庫を作成。
3. 写真を選んで追加。目安として500枚まで。
4. 「設定」から暗号化バックアップを定期的にダウンロード。
5. Safariの共有メニューから「ホーム画面に追加」できる。

## 重要な注意

- 写真の中身はGitHubへアップロードされません。GitHub上にあるのはアプリのコードと画像アイコンです。
- 写真は各端末・ブラウザのIndexedDBに保存されます。**ほかの端末とは同期しません**。
- ブラウザデータの消去・端末の故障・保存容量の制限により写真が失われることがあります。特にiPhoneはブラウザの保存領域が予期せず削除される場合があります。
- バックアップと復元には元のパスワードが必要です。忘れると復旧できません。
- 500枚はUI上の枚数制限であり、**端末の空き容量・ブラウザ制限によっては500枚保存できません**。
- ウェブサイトは公開されています。アプリのパスワードを設定する前に、ご自身の端末でHTTPSの正規URLに接続していることを確認してください。
- ホーム画面に追加したアプリとSafariで開いたページでは、保存領域が別になることがあります。
